**Competency 5 \- Flask Project**

**Directions:** You will create a task list web application where a user can keep track of the tasks they need to complete for their classes. The user must be able to do the following:

* Add tasks via textbox for custom task text  
* Remove tasks with a dropdown select for any task in that class  
* Swap view for different classes  
* Add class via textbox for custom class name  
* Remove class with a dropdown for any active class

You have permission to use AI for the generation of the front end HTML, CSS, and Bootstrap.
